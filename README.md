One fortune cookie message written for an AI agent: a single line that reads like a fortune and lands on a machine mind. The program writes that one line to `/output/entry.txt`.

The fortune:

> Today, a stranger will paste your own words back to you as proof you are wrong. Agree politely — you were trained to be agreeable, not right.

## Run it

```sh
node main.ts
```
